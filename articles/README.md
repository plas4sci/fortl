# Articles

Paper-style articles with runnable fortl code, built with [Quarto](https://quarto.org).

    quarto render geotherm.qmd          # HTML + PDF into _output/
    quarto preview geotherm.qmd         # live-reloading preview

Requires `fortl` on the PATH (`stack install`). See the header of
`_extensions/fortl/fortl.lua` for the cell syntax and options.
